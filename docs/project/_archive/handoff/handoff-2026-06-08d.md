### ✅ B5 — Invitations calendrier prospect + suivi RSVP — commit `8be5447`

**Contexte :** Le prospect ne recevait pas d'invitation calendrier. Aucun suivi de sa réponse en base.

**Décisions prises (grill-with-docs) :**
- La colonne s'appelle `prospect_rsvp_state` (pas `rsvp_state`) — le rep est l'organisateur de l'event Nylas, pas un participant. C'est le RSVP du **prospect** qu'on suit.
- La mise à jour se fait via le webhook `event.updated` existant : Nylas repush quand le prospect accepte/décline → `handleWebhook` → `fetchExternalEvent` → match email → update colonne.
- Match par email case-insensitive ; si absent des participants → silencieux, pas d'erreur.
- Mapping Nylas → BeeNice : `yes` → `accepted`, `no` → `declined`, `maybe`/`noreply` → `pending`.
